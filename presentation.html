Techno

Ce qui fait tourner l'application.

Techno

La stack

Socle

  • Expo SDK 57
  • React Native 0.86 · React 19
  • TypeScript

Navigation

  • Expo Router (routes par fichiers)
  • /, /manga/[id], /profil
  • Barre d'onglets maison

Style

  • NativeWind (Tailwind CSS)
  • Tokens : ink, background, outline, primary
  • Police Inter · contrastes WCAG AA

Données

  • API api.tenrai.org/v1/manga
  • AsyncStorage : comptes, filtres, favoris
  • Context : Auth et Favoris
expo-image expo-calendar expo-splash-screen react-native-reanimated @expo/vector-icons

Techno

Organisation du code

src/app

Les routes Expo Router et le layout racine (polices, splash, providers).

src/views

Les écrans : Homepage, MangaList, UpdateUser.

src/components

Les briques réutilisables : MangaCard, ReleaseCalendar, TabBar, SignIn…

src/api

Les appels à l'API manga, le stockage utilisateur et l'agenda du téléphone.

src/context

L'état global : utilisateur connecté et favoris.

src/theme

Les couleurs en variables CSS, reprises par Tailwind.

03

Démo

L'application en vrai, sur le téléphone.

Démo

Le parcours

  1. Splash animé, puis inscription et connexion
  2. Choix du type de livre et des genres préférés
  3. Liste des mangas filtrée, chargée page par page depuis l'API
  4. Fiche d'un manga : détails, illustrations, ajout aux favoris
  5. Calendrier des sorties et ajout d'une sortie à l'agenda du téléphone
  6. Profil : « Ma liste », modification du pseudo et des filtres
